# FairPick

> Everyone gets a say. Nobody gets the blame.

FairPick is a simple group decision maker.

When a group cannot decide where to eat, what to watch, what to do, or which option to choose, everyone adds one choice and FairPick randomly selects the winner.

## Core idea

Everyone chooses.

FairPick decides.

Everyone moves on.

## Features

- Add multiple choices
- No names required
- No account required
- No voting
- Duplicate choices are supported
- Equal probability per choice entry
- Secure browser randomness when available
- Animated decision reveal
- Copy result
- Share result
- Start another FairPick
- Local browser persistence
- Responsive mobile and desktop UI
- Reduced-motion support
